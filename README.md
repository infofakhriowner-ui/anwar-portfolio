# Anwar Ali — Personal Portfolio

A responsive, clean-light personal portfolio built with **HTML, CSS, and vanilla JavaScript**. No framework and no build process required.

## Run locally

1. Open this folder in VS Code.
2. Open `index.html` in a browser, or install VS Code's **Live Server** extension and select **Open with Live Server**.
3. Edit `index.html` for text and links, `style.css` for design, and `script.js` for interactions.

## Customize before publishing

- Replace `hello@example.com` with your own email in `index.html`.
- Verify the personal intro, projects, claims and service descriptions.
- The dashboard chart and project images are **stylized illustrations**, not actual performance data or screenshots.
- Replace illustrations with real approved screenshots and add actual verified case study metrics if available.
- Add professional profile photo and social/contact links as desired.
- Google Fonts require an internet connection; system font fallbacks still work offline.

## Deploy to Vercel

Push the folder contents to a GitHub repository, import the repository in Vercel, and deploy it as a static site. No build command or output directory is necessary for these root-level files.
